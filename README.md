# Homebrew tap for crossdrop

[crossdrop](https://github.com/root-lr/crossdrop) is a simple, open-source way to share your clipboard and files across devices.

```bash
brew install root-lr/crossdrop/crossdrop                # crossdrop, crossdropd, interdesk
brew services start crossdrop                           # keep the daemon running
brew install --cask root-lr/crossdrop/crossdrop-app     # the desktop app (macOS)
```

Update with `brew upgrade crossdrop` and `brew upgrade --cask crossdrop-app`.

This tap is updated automatically by crossdrop's release workflow: please open issues and pull requests in the [main repository](https://github.com/root-lr/crossdrop).
